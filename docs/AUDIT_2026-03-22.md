## 11. FLUSSI UTENTE PRINCIPALI

### Flusso 1: Setup nuova famiglia (genitore)
```
Step 1: Benvenuto + privacy
Step 2: Ruolo (genitore) + nome
Step 3: Composizione famiglia (genitori, nonni, figli)
Step 4: PIN genitori + PIN figli
Step 5: Permessi personalizzati
Step 6: Sync cloud (opzionale)
Step 7: Riepilogo → Conferma → Login
```

### Flusso 2: Join famiglia (figlio) — NUOVO
```
Step 1: Benvenuto
Step 2: Ruolo (figlio/a) + nome
Step 3: Inserisci codice invito 6 char
      → Seleziona "Chi sei?" dalla griglia figli
      → Skip step 4-7 → Login diretto
```

### Flusso 3: Login giornaliero
```
Apri app → Seleziona membro → Inserisci PIN → Dashboard
```

### Flusso 4: Brain (NLP)
```
Input testo/voce → Parse locale (NLP.js L0-L2)
  → Se bassa confidenza: fallback Claude Haiku (5s timeout)
  → Preview sheet (Anteprima)
  → Conferma/Modifica/Rifiuta
  → Esecuzione azione (evento/spesa/task)
  → Learning engine (rinforzo positivo/negativo)
```

### Flusso 5: Sync cloud
```
Modifica locale → Dexie write
  → Push to Supabase (conditional_upsert, LWW)
  → Pull from Supabase
  → Merge conflicts (Last Writer Wins)
  → Decrypt sensitive fields
```
